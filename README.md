치지직을 더 편하게 쓰도록 검색·플레이어·레이아웃 기능을 한데 모은 브라우저 확장 프로그램입니다. 채널의 `동영상` 탭과 `클립` 탭에 검색 도구를 추가하고, 별도 팝업 창에서는 스트리머 닉네임으로 다른 채널의 콘텐츠도 검색할 수 있습니다. 라이브와 다시보기 플레이어에서는 오디오 믹서·비디오 필터로 방송별 소리와 화면을 보정하고, 실시간 따라잡기로 라이브 지연을 줄일 수 있습니다. 헤더와 사이드바를 정리하고, 사이드바를 숨겨도 헤더 바로가기로 주요 메뉴에 접근할 수 있습니다. 네이버 카페 게시글의 치지직 클립 링크는 글 안에서 바로 재생할 수 있습니다. 확장 아이콘의 기능 설정에서 필요한 기능만 카테고리별로 켜고 끌 수 있습니다.

---

## 주요 기능

### 다시보기 검색

- 제목, 태그, 카테고리 검색을 지원합니다.
- 시작일/종료일과 빠른 기간 선택을 제공합니다.
- 달력에서 `2023년`부터 현재 년도까지 년/월을 빠르게 선택할 수 있습니다.
- 길이 필터, `다시보기`, `업로드`, `시청 중`, `시청안함` 유형 필터를 제공합니다.
- 최신순, 오래된순, 조회순, 댓글 많은순, 라이브 시청순 정렬을 지원합니다.
- 시청 중인 영상은 카드 하단 진행 바로 시청 위치를 표시합니다.
- 검색 결과를 표시할 때 기존 치지직 페이지네이션은 숨기고, 초기화하면 원래대로 복구합니다.

### 카테고리 동영상 필터

- 기본 꺼짐 옵션을 켜면 카테고리의 `동영상` 탭에 전체·24시간·7일·30일 등록 기간과 최신순·오래된순·인기순 정렬 탭을 치지직 클립 탭과 같은 형태로 표시합니다.
- 기간 또는 정렬 탭을 누른 경우에만 카테고리 동영상 API를 `50개`씩 순차 확인하며, 기간 범위에 도달하거나 설정한 후보 수를 확인하면 수집을 멈춥니다. 후보 수는 `500개`, `1,000개`, `2,000개`, `3,000개`, `5,000개` 중에서 선택할 수 있고 기본값은 `2,000개`입니다. 현재 결과를 끝까지 내리면 하단의 `동영상 N개 더 확인`으로 같은 수만큼 이어서 수집할 수 있습니다. 24시간·7일·30일의 오래된순은 선택 기간의 시작점부터 확인해 방송량이 많은 카테고리에서도 최근 동영상만 반복되는 문제를 줄입니다.
- 필터 결과는 치지직 원본 동영상 카드의 레이아웃을 복제해 내용과 썸네일만 바꾸고, 최근 카테고리 `3개`까지 `1시간` 동안 로컬 캐시해 같은 조건의 반복 요청을 줄입니다. 옵션을 끄거나 페이지를 이동하면 원본 목록을 복원합니다.
- 상태 영역에서 현재 카테고리 캐시를 삭제하고 최신 동영상을 다시 확인하거나, 기간·정렬 필터를 초기화해 치지직 원본 목록으로 돌아갈 수 있습니다.

### 통합검색

- 치지직 통합검색(`/search`)의 라이브 결과를 더 넓게 수집해 제목·채널명 관련도, 현재 시청자 수, 파트너 채널 여부와 방송 시작 시각을 기준으로 재정렬할 수 있습니다.
- 통합검색 라이브 결과 상단에서 추천순, 시청자순, 최신순, 치지직 원본순을 전환하고 기본 정렬과 추천순 점수 비중을 설정 또는 결과 화면의 팝오버에서 조절할 수 있습니다. 라이브 재정렬은 기본적으로 꺼져 있습니다.
- 치지직 통합검색(`/search`)의 동영상 결과를 더 넓게 수집해 제목·채널명 관련도, 조회수, 라이브 시청자 수, 파트너 채널 여부, 최신성을 기준으로 재정렬할 수 있습니다.
- 통합검색 동영상 결과 상단에서 추천순, 인기순, 라이브 시청순, 최신순, 치지직 원본순 정렬을 전환할 수 있습니다.
- 재정렬 후보 최대 개수와 추천순 점수 비중을 설정에서 조정할 수 있습니다. 기본 비중은 제목 관련도 `35`, 채널명 관련도 `15`, 조회수 `25`, 라이브 시청자 `10`, 파트너 채널 `10`, 최신성 `5`이며 초기화할 수 있습니다.
- 추천순 점수 비중을 모두 `0`으로 입력하면 기본 비중으로 자동 복구해 추천 점수가 모두 같아지는 상황을 방지합니다.
- 원본 동영상 카드 구조를 복제해 썸네일, 채널, 조회수, 날짜, 카테고리·태그, 더보기/접기 버튼을 치지직 화면과 어울리게 표시합니다.
- 원본 카드의 인증 마크와 업적 배지가 완성된 뒤 이를 수집해 재정렬 카드에도 같은 아이콘 구조로 표시하고, 수집할 원본 배지가 없는 검색 결과는 API 배지 정보로 보완합니다.
- 실험 기능을 켜면 통합검색에 없는 클립 결과를 최근 인기·추천 피드, 검색어 태그로 찾은 라이브·다시보기 채널, 팔로잉 채널, 관련 채널과 검색 후보에서 많이 나타난 카테고리의 클립을 조합해 표시합니다. 전체 클립 검색 API가 아니므로 후보에 없는 클립은 누락될 수 있으며 기본값은 꺼짐입니다.
- 통합검색 클립은 제목·카테고리·채널명·조회수·파트너 채널·최신성 점수를 이용한 관련순과 조회순·최신순 정렬, 전체·30일·7일·24시간 날짜 범위, 정확·균형·넓게 후보 범위를 지원합니다.
- `@음악`, `@"종합 게임"`처럼 카테고리를 지정하면 해당 카테고리 후보를 우선 수집한 뒤 나머지 검색어와 일치하는 클립을 찾습니다.
- 추천·태그·팔로잉·관련 채널을 합친 기본 후보와 카테고리 후보 수를 각각 `50~100,000개` 범위에서 조절할 수 있습니다. 기본 후보는 추천 50%, 관련 채널 25%, 태그 채널 15%, 팔로잉 채널 10%로 배분하며, 큰 값은 검색 시간과 메모리·API 요청량을 크게 늘릴 수 있습니다. 기본값은 각각 `1,000개`입니다.
- 클립 후보 출처 배분은 `균형`, `검색어 중심`, `팔로잉 중심`, `커스텀` 중에서 선택할 수 있습니다. 커스텀 가중치는 추천 `40~70`, 관련 채널 `10~35`, 태그 채널 `0~25`, 팔로잉 채널 `0~20` 범위에서 조절하고 실제 목표 비율은 100%로 자동 환산하며, 다른 프리셋을 사용해도 마지막 커스텀 값은 별도로 유지합니다. 성능 보호를 위해 관련 채널 `10,000개`, 태그 채널 `2,000개`, 팔로잉 채널 `1,000개`의 절대 상한을 적용하고 남는 후보는 추천 피드에 배분합니다.
- 클립 헤더에서 최신 후보를 다시 확인할 수 있고 다음 검색의 기본 정렬을 관련순·인기순·최신순 중에서 선택할 수 있습니다. 상위 후보의 클립 태그도 제한적으로 확인해 제목·채널명만으로 찾기 어려운 결과를 보완합니다.
- 동영상과 클립 섹션의 설정 팝오버에서 정렬·점수·후보 범위·날짜 범위를 바로 조절하고, 더보기 증가량과 섹션 맨 위로 이동하는 FAB를 각각 설정·사용할 수 있습니다.
- 클립 카드는 기본적으로 자동재생 요청을 포함한 클립 페이지를 새 탭으로 엽니다. `클립 클릭 시 바로 재생`을 켜면 검색 화면 위에서 음소거로 재생하고 `소리 켜기` 버튼을 표시합니다.

### 라이브 탐색

- 전체 방송과 팔로잉의 `전체`·`라이브` 탭에서 제외할 태그 또는 카테고리를 등록해 일치하는 방송 카드를 숨길 수 있습니다.
- 탐색 페이지의 `제외 필터 추가` 버튼에서 필터를 추가하고 개별·선택·전체 삭제할 수 있으며, 같은 목록을 기능 설정의 `라이브 탐색` 탭에서도 관리할 수 있습니다.
- 제외 필터 버튼 표시 여부를 별도로 설정할 수 있고, 저장한 제외 항목은 탐색 목록이 다시 렌더되어도 계속 적용됩니다.
- 메인, 전체 방송, 카테고리와 팔로잉 라이브 카드의 시청자 수를 `LIVE` 배지 옆으로 옮기거나 완전히 숨길 수 있습니다.

### 다시보기 타임스탬프

- 다시보기 댓글에 포함된 `1:23`, `1:23:45`, `(1:23)` 형식의 타임스탬프를 플레이어 슬라이더에 마커로 표시합니다.
- 댓글 타임스탬프 버튼으로 마커 목록을 열고, 항목을 클릭해 해당 재생 위치로 이동할 수 있습니다.
- 타임스탬프 항목을 클릭한 뒤 목록을 즉시 닫거나 계속 유지하거나, `1~10초` 뒤 닫도록 설정할 수 있습니다.
- 타임스탬프 마커에 마우스를 올리면 플레이어 미리보기 아래에 댓글 내용을 표시합니다.
- 댓글 타임스탬프 버튼은 플레이어가 다시 렌더되어도 클릭과 우클릭 동작을 유지하고, 마커 미리보기는 기존 요소를 재사용해 빠른 호버 시 화면 갱신 부담을 줄입니다.
- 다시보기 재생바를 탐색할 때 미리보기 시간 아래에 방송 당시 시각을 함께 표시합니다. 다시보기 채팅에서 실제 전송 시각과 영상 경과 시각을 여러 건 확보하면 방송 시작 시각을 보정하고, 확보하지 못하면 기존 추정 시각을 사용합니다.
- 기본 꺼짐인 `채팅 활성도`를 켜면 다시보기 채팅을 구간별로 집계해 재생바 위에 밀도 그래프를 표시하고, 치즈 후원·구독 구간을 지정한 색으로 함께 구분합니다. 긴 영상은 진행률을 표시하고 수집을 중단할 수 있으며, 완성된 집계는 최근 영상 `60개`까지 캐시합니다.
- 타임스탬프 목록을 열면 현재 재생 시간이 속한 항목을 강조하고, 재생 위치가 다음 구간으로 넘어가면 강조 항목도 함께 이동합니다.
- 타임스탬프 목록 패널에서 재생바 마커 표시를 켜고 끌 수 있습니다.
- 댓글 타임스탬프 버튼 우클릭 메뉴에서 타임스탬프 기능 전체를 켜고 끌 수 있습니다.
- `bestComments`와 설명이 있는 댓글을 우선 표시하고, `3초` 이내의 비슷한 타임스탬프는 하나로 묶습니다.
- 한 댓글 안에 여러 타임스탬프가 있거나 괄호 안에 추가 타임스탬프가 있는 경우도 각각 추출합니다.
- `오프닝 1:23`처럼 설명이 타임스탬프 앞에 오는 형식도 타임스탬프 제목으로 인식합니다.
- 타임스탬프가 없으면 버튼을 흐리게 표시하고 팝업이 열리지 않도록 처리합니다.
- AI 챕터로 재생바가 여러 구간으로 나뉜 다시보기에서도 영상 전체 길이를 기준으로 타임스탬프 마커를 표시합니다.
- 세로형 다시보기에서는 탐색 미리보기의 방송 당시 날짜와 시각을 두 줄로 나눠 좁은 화면 밖으로 잘리지 않도록 표시합니다.

### 오디오 믹서

- 치지직 라이브와 다시보기 플레이어 하단에 오디오 믹서 버튼을 추가합니다.
- `Shift+A` 단축키로 오디오 믹서 버튼 클릭과 같은 동작을 실행할 수 있고, 열린 믹서 패널은 `Esc`로 닫을 수 있습니다.
- 기본, 저챗·라디오, 게임 방송, 야외방송, 노래 방송, 클래식·재즈, 영화·드라마, 애니, 스포츠, ASMR 프리셋을 제공합니다.
- 초보자용 원클릭을 켜면 버튼 한 번으로 `기본` 프리셋을 패널 없이 바로 켜고 끌 수 있습니다.
- 고급 슬라이더와 전문가 모드에서 게인, EQ, 컴프레서, 리미터, 노멀라이저 목표 레벨을 조정할 수 있습니다. 전문가 모드의 수치는 슬라이더뿐 아니라 숫자 입력으로 정밀하게 조절할 수 있습니다.
- 오디오 믹서가 켜져 있을 때 플레이어 하단 믹서 버튼 옆에서 마스터 게인을 바로 조절할 수 있습니다.
- 치지직 음량 슬라이더와 오디오 믹서 마스터 게인 슬라이더를 조절할 때 현재 값을 % 툴팁으로 표시합니다.
- 치지직 기본 음량 슬라이더가 접힌 상태에서도 볼륨 컨트롤 위에 마우스를 올리거나 조작하면 % 툴팁을 안정적으로 표시합니다.
- 확장 설정에서 볼륨/게인 % 툴팁 표시 여부와 영상 위 마우스 휠 볼륨 조절, 휠 조절 간격을 설정할 수 있습니다.
- 페이지 스크롤을 유지하면서 마우스 오른쪽 버튼을 누른 상태의 휠만 영상 볼륨 조절에 사용하도록 설정할 수 있습니다.
- 확장 설정에서 게인 슬라이더의 최소/최대 범위와 플레이어·믹서 패널의 게인 조절 간격을 `1~10%`로 설정할 수 있습니다.
- 사용자 지정 게인 최소값이 `50%`보다 낮아도 페이지 새로고침이나 방송 전환 후 저장된 게인 값을 그대로 복원합니다.
- 확장 설정에서 `오디오 믹서 항상 켜기`를 켜면 페이지 첫 조작 이후 믹서를 자동으로 활성화합니다.
- 브라우저가 자동재생 오디오를 허용한 상태에서는 같은 탭에서 페이지 복귀나 영상 교체 후에도 믹서 켜짐 상태를 재생 시작에 맞춰 복원합니다. 새 탭에는 과거 채널의 켜짐 상태를 자동 적용하지 않으며, `항상 켜기`를 사용하면 저장 프리셋을 불러온 뒤 활성화하고 백그라운드에서 열린 탭은 화면에 나타날 때 연결을 다시 확인합니다.
- `믹서 버튼 클릭 시 바로 켜기`를 켜면 버튼 클릭만으로 믹서를 즉시 활성화할 수 있으며, 하위 옵션으로 패널을 열지 않고 효과만 켜고 끌 수 있습니다.
- 확장 설정에서 내장 프리셋 또는 커스텀 프리셋을 채널과 상관없이 적용할 전역 기본값으로 지정할 수 있습니다.
- 오디오 믹서 전역 기본값은 채널 재방문 시 항상 전역값을 우선할지, 해당 채널에서 직접 선택한 프리셋을 우선할지 설정할 수 있습니다.
- 프리셋을 수정한 뒤 현재 설정을 커스텀 프리셋으로 저장하고, 커스텀 프리셋을 수정하거나 삭제할 수 있습니다.
- 커스텀 프리셋은 JSON으로 내보내거나, 공유받은 JSON을 붙여넣어 불러올 수 있습니다.
- 커스텀 프리셋을 `기본` 프리셋 대체값으로 등록해 기본 칩에서 바로 적용할 수 있습니다.
- 프리셋을 수정한 상태에서는 적용 중이던 프리셋 이름을 표시하고, 초기화 버튼으로 수정 전 프리셋 값으로 되돌릴 수 있습니다.
- 프리셋별 노멀라이저 목표 레벨과 리미터 값을 적용해 방송 유형에 맞는 음량 보정을 제공하며, 기본 프리셋은 적당한 컴프레서와 최종단 리미터로 체감 음량과 클리핑 방지를 함께 보정합니다.
- 믹서 버튼의 상태 표시 dot으로 활성/비활성 상태를 구분합니다.
- 플레이어가 미니플레이어로 전환되거나 재렌더되어도 오디오 믹서 연결을 유지하거나 새 영상 요소에 다시 연결합니다.
- 같은 영상의 오디오 소스를 다른 확장 프로그램이 이미 사용 중이면 믹서를 끄고 충돌 안내를 표시합니다.
- 치지직 클립 페이지에서는 볼륨 버튼 위의 원클릭 오디오 믹서로 선택한 내장·커스텀 프리셋을 적용할 수 있습니다. 클립 전환에도 켜짐 상태를 유지하며, 브라우저가 Web Audio 자동 실행을 허용하면 즉시 켜고 차단한 경우에만 첫 사용자 조작을 기다립니다.
- 치지직 클립 페이지에서는 오디오 믹서 위의 원클릭 비디오 필터로 선택한 내장·커스텀 프리셋을 켜고 끌 수 있으며, 기본 프리셋은 `화질 향상`입니다.
- 스트림 정보 버튼으로 해상도, FPS, 비트레이트, 코덱, 라이브 레이턴시, 오디오 정보와 하드웨어 가속 사용 여부를 확인할 수 있습니다.
- 스트림 정보는 `Shift+I`, 탭 음소거는 `Shift+M` 단축키로 열거나 토글할 수 있습니다.
- 스트림 정보, 탭 음소거, 스크린샷, 되감기, 앞으로, 실시간 따라잡기 버튼을 왼쪽/오른쪽 컨트롤 그룹과 네이티브 버튼 사이 원하는 위치로 드래그 배치할 수 있습니다.
- 플레이어 하단의 `탭 음소거` 버튼으로 치지직 플레이어 음소거와 별개로 브라우저 탭 전체를 음소거하거나 해제할 수 있습니다.
- 플레이어 하단의 `스크린샷` 버튼이나 `Shift+S` 단축키로 현재 재생 화면을 PNG로 저장할 수 있습니다. 저장 전 미리보기에서 원하는 영역을 이동·크기 조절해 잘라 저장하거나 바로 저장하도록 설정할 수 있습니다.
- 라이브 상세의 시청자 수/스트리밍 시간 영역에 마우스를 올리면 라이브 시작일을 툴팁으로 확인할 수 있습니다.
- 라이브와 다시보기 진입 시 치지직 플레이어의 `넓은 화면` 모드를 자동으로 켤 수 있습니다. 플레이어 버튼이 늦게 준비되는 경우에도 적용 전까지만 짧게 재시도합니다.
- 라이브와 다시보기 시청 시 가장 높은 고정 화질로 자동 전환하고, 사용자가 직접 화질을 낮추면 해당 영상 동안 그 선택을 존중하도록 설정할 수 있습니다.
- 최대 화질 자동 고정은 재생이 안정된 뒤 치지직 화질 메뉴의 실제 항목 클릭 경로를 우선 사용하고, 라이브 전환 후 지연이 생기면 실시간 따라잡기로 엣지 복귀를 보조합니다. 여러 방송을 열어 둔 경우에는 현재 보이는 탭에만 최대 화질을 강제하고 탭으로 돌아오면 즉시 다시 확인하며, 라디오 모드에서는 화질 전환을 멈췄다가 영상 복귀 후 다시 적용합니다.
- 라이브·다시보기에서 다른 치지직 페이지로 이동할 때 영상이 작은 창(PIP)으로 남는 전환을 끌 수 있습니다.
- 라이브와 다시보기의 `화면 채우기`를 각각 켜고 영상 레터박스를 줄이도록 플레이어 영역 높이를 보정할 수 있습니다.
- 플레이어 오류 다이얼로그가 일정 시간 유지되면 반복 새로고침을 막는 조건 안에서 페이지를 자동 새로고침할 수 있습니다.
- 방송 종료 화면이 떠 있는 상태에서 같은 채널이 다시 라이브를 시작하면 페이지를 자동 새로고침하도록 설정할 수 있습니다.
- 중간광고 중 원래 방송이 미니플레이어로 축소될 때, 옵션을 켜면 방송 음소거를 해제해 광고 중에도 방송 소리를 계속 들을 수 있습니다. 단, 광고 진입 전 원래 음소거였던 경우는 그대로 유지하도록 설정할 수 있습니다.
- 치지직 음량 슬라이더·오디오 믹서 게인 슬라이더·영상 위 휠 볼륨과 되감기·앞으로 조작 시 플레이어에 현재 음량, 게인 또는 이동 시간을 잠시 표시하는 화면 피드백을 켜고 끌 수 있습니다. 볼륨·게인, 되감기, 앞으로 OSD를 각각 숨기거나 위치를 개별 조정할 수 있습니다.
- 라이브 플레이어에서 설정한 간격의 `되감기`와 `앞으로` 버튼으로 seekable 구간 안에서 이동할 수 있고, 버튼이나 좌우 방향키를 길게 눌러 연속 이동할 수 있습니다. 되감은 위치는 치지직의 라이브 엣지 자동 동기화와 자동 따라잡기에 의해 즉시 원래 위치로 돌아가지 않도록 보호합니다.
- 다시보기 플레이어에도 라이브와 같은 위치·아이콘의 `5초 되감기`와 `5초 앞으로` 버튼을 표시할 수 있으며, 기본값은 꺼짐입니다.
- 다시보기에서 `플레이어 포커스 없이 방향키 이동`을 켜면 다른 탭에서 돌아온 뒤 영상을 클릭하지 않아도 좌우 방향키로 `5초`씩 이동할 수 있습니다. 입력창·슬라이더처럼 방향키를 자체적으로 사용하는 UI에서는 동작하지 않습니다.
- 라이브 플레이어 컨트롤 위에 되감기 가능 구간 바를 표시하고, 바를 드래그해 원하는 지점으로 이동할 수 있습니다. 되감기/앞으로 버튼을 숨겨도 되감기 바는 별도로 유지할 수 있으며, 화면 아래에서 떨어진 위치를 `35~445px` 범위로 조절할 수 있습니다.
- 라이브 지연이 커지면 `실시간 따라잡기` 버튼을 활성화하고, 클릭하거나 `Shift+F`를 눌러 일시적으로 배속을 높여 라이브 엣지에 가까워지도록 보정합니다.
- `실시간 따라잡기` 버튼 우클릭 메뉴에서 자동 따라잡기를 켜면 라이브 지연이 커질 때 자동으로 따라잡기를 실행합니다.
- 확장 설정에서 실시간 따라잡기 민감도를 `낮음`, `보통`, `높음` 프리셋이나 `커스텀`(시작/목표 지연 직접 입력)으로 조정할 수 있습니다.
- 실시간 따라잡기는 배속으로 지연을 서서히 줄이거나 라이브 엣지로 즉시 이동하는 방식을 선택할 수 있습니다.
- 실시간 따라잡기 배속을 `1.2배`, `1.5배`, `2배`, `3배` 중에서 선택하고, 자동 따라잡기 재발동 쿨다운의 사용 여부와 기본·최대 간격을 조정할 수 있습니다.
- 라디오 모드처럼 오디오 전용 스트림인 경우 스트림 정보 패널에서 비디오 정보를 비우고 오디오 전용 상태와 오디오 비트레이트를 우선 표시합니다.

### 비디오 필터

- 치지직 라이브와 다시보기 플레이어 하단에 비디오 필터 버튼을 추가합니다.
- `Shift+V` 단축키로 비디오 필터 버튼 클릭과 같은 동작을 실행할 수 있고, 열린 필터 패널은 `Esc`로 닫을 수 있습니다.
- 밝기, 노출, 대비, 채도, 색온도, 색조, 감마, 선명도, 그림자, 하이라이트를 조정할 수 있습니다.
- 원본, 화질 향상, FPS 게임, 롤·AOS, 게임 일반, 공포 게임, 야외방송, 스포츠, 먹방·쿡방, 캠방송, 버츄얼, 애니·2D, 야간 시청, 시네마틱 프리셋을 제공합니다.
- 초보자용 원클릭을 켜면 버튼 한 번으로 `화질 향상` 프리셋과 선명도 자동 조절을 패널 없이 바로 켜고 끌 수 있습니다.
- CSS filter와 SVG filter를 함께 사용해 기본 색감 보정뿐 아니라 감마, 선명도, 그림자, 하이라이트 보정을 적용합니다.
- 선명도가 높은 필터를 적용할 때 하드웨어 가속이 꺼져 있거나 판정할 수 없는 경우에만 안내를 표시하고, 프레임 드롭이 감지되면 선명도를 일시적으로 낮추는 자동 조절 옵션을 제공합니다. 성능 측정은 짧은 주기별 표본으로 처리해 상시 프레임 감시 부담을 줄입니다.
- 선명도 자동 조절은 실제 재생·드롭 프레임을 일정 간격으로 비교하고, 성능 보호가 동작하면 패널에 현재 적용 비율을 표시합니다.
- 확장 설정에서 `비디오 필터 항상 켜기`를 켜면 채널의 저장 프리셋과 직접 끈 상태를 먼저 불러온 뒤 필터를 자동으로 활성화합니다.
- `필터 버튼 클릭 시 바로 켜기`를 켜면 버튼 클릭만으로 필터를 즉시 활성화할 수 있으며, 하위 옵션으로 패널을 열지 않고 효과만 켜고 끌 수 있습니다.
- 확장 설정에서 내장 프리셋 또는 커스텀 프리셋을 채널과 상관없이 적용할 비디오 필터 전역 기본값으로 지정할 수 있습니다.
- 비디오 필터 전역 기본값도 채널 재방문 시 전역값 우선 또는 직접 선택 우선 방식을 고를 수 있습니다.
- 프리셋을 수정한 뒤 현재 설정을 커스텀 프리셋으로 저장하고, 수정 전 프리셋 값으로 초기화할 수 있습니다.
- 커스텀 비디오 필터 프리셋은 JSON으로 내보내거나, 공유받은 JSON을 붙여넣어 불러올 수 있습니다.

### 팝업 플레이어

- 사이드바의 라이브 채널을 페이지 본문으로 끌어다 놓아 떠 있는 플레이어로 재생할 수 있으며, 여러 방송을 동시에 열 수 있습니다.
- 팝업 상단을 드래그해 위치를 옮기고 우하단을 끌어 크기를 조절할 수 있으며, 초기 크기는 프리셋 또는 `240~2000px` 범위의 사용자 값으로 지정할 수 있습니다.
- 여러 팝업의 소리를 `모두 음소거`, `첫 팝업만`, `모두 소리` 중에서 선택할 수 있습니다.
- 팝업에 넓은 화면을 자동 적용하고, 팝업 전용 최대 화질 자동 고정을 별도로 켜고 끌 수 있습니다.
- 작은 팝업에서 화면 아래쪽 내용에 접근할 수 있도록 팝업 iframe 내부의 가로·세로 스크롤을 허용할 수 있습니다.
- 오디오 믹서, 비디오 필터, 실시간 따라잡기, 되감기 바, 스트림 정보, 스크린샷, 되감기·앞으로 버튼 표시 여부를 팝업 전용 설정으로 관리할 수 있습니다.
- 팝업에서 숨긴 버튼은 단축키 기능을 유지하거나 기능까지 함께 끌 수 있습니다. 탭 음소거는 본창까지 영향을 주므로 팝업에서는 제공하지 않습니다.
- 팝업용 채널 드래그 중에는 기존 팔로잉 미리보기가 함께 열리지 않으며, 팝업을 닫거나 기능을 끄면 iframe과 관련 이벤트를 정리합니다.

### 채팅 정리

- 채팅창의 후원 랭킹과 통나무파워 랭킹을 각각 숨기고, 진행 중인 미션, 승부예측 패널, 파티 후원 패널, 후원·구독·미션 메시지를 숨길 수 있습니다.
- 채팅창 좌측 경계를 드래그해 너비를 조절하고, 채팅창을 플레이어 왼쪽에 배치할 수 있습니다.
- 채팅창을 왼쪽에 배치하면 너비 조절을 켜지 않아도 프로필·클린봇·이모티콘 다이얼로그를 현재 채팅 폭에 맞춰 표시합니다.
- 채팅창을 자동으로 숨기고, 마우스를 화면 좌우 가장자리 근처에 가져가면 슬라이드로 다시 표시할 수 있습니다.
- 치지직 `채팅 접기` 버튼으로 접은 상태를 기억하고, 새로고침·재접속 후 라이브에 들어올 때 접힘 상태로 복원할 수 있습니다.
- 다시보기 채팅창도 너비 조절과 왼쪽 배치를 지원하며, 조절한 너비에 맞춰 영상 정보 영역과 미니플레이어 폭을 보정합니다.
- 채팅창 위 배너 광고가 조절한 채팅 폭을 벗어나지 않도록 배너와 내부 광고 영역의 폭을 함께 보정합니다.
- 채팅 폰트, 이모티콘, 배지 크기를 `80%`부터 `200%`까지 조절할 수 있습니다.
- 채팅 폰트 배율 적용 시 인증/업적 배지의 원래 크기를 존중해 확대하고, 채팅 안 프로필 카드와 배지 선택 UI는 원본 크기를 유지합니다.
- 각 채팅 앞에 보낸 시각을 표시하고, `24시간`, `AM/PM`, `오전/오후` 형식과 라이트·다크 모드별 글자 색상을 선택할 수 있습니다. 사용자 지정 색상을 끄면 치지직의 기존 테마 색상을 유지합니다.
- 각 채팅에 치지직이 전달한 작성 기기 정보를 PC·안드로이드·iOS 아이콘으로 표시하고, 아이콘을 채팅 시간 앞이나 뒤에 배치할 수 있습니다. 기기별 SVG를 직접 등록하거나 PNG·JPG·WebP 이미지를 선택해 기본 아이콘 대신 사용할 수 있습니다. SVG의 안전하지 않은 요소와 외부 리소스는 제거하며, 이미지는 `64×64px` 이내의 정적 WebP로 변환해 저장합니다.
- 채팅 닉네임과 배지를 각각 숨길 수 있으며, 대화 맥락을 위해 스트리머·매니저·파트너는 그대로 표시합니다.
- 일반 단어 또는 정규식 규칙을 등록해 일치하는 라이브·다시보기 채팅과 플로팅 새 채팅을 숨길 수 있습니다. 잘못된 정규식과 중복 규칙은 저장 전에 확인합니다.
- 라이브 최초 진입 후 치지직 React 렌더가 시간 요소를 제거하더라도 해당 채팅 행만 감지해 다시 표시하며, 아직 준비되지 않은 행은 짧게 제한 재시도합니다.
- 라이브에서 클린봇 또는 블라인드로 가려진 채팅을 원문으로 복원해 흐린 이탤릭 텍스트로 구분해 표시할 수 있습니다. 다시보기에서는 원문이 함께 제공되는 클린봇 메시지만 복원하고, 원문이 남지 않은 블라인드 메시지와 관리자 전용 채팅 같은 시스템 상태 안내는 반복 처리하지 않습니다.
- 처음 가려진 블라인드 채팅도 캐시된 원문이 있으면 즉시 복원하도록 보강했습니다.
- 가려지기 전의 채팅 원문을 일정량 캐시해 치지직이 내부 원문을 비운 뒤에도 같은 행의 복원 성공률을 높입니다.
- 일반 채팅의 시간·작성 기기·배지·닉네임은 첫 줄에 두고 메시지 내용을 다음 줄에 표시하도록 설정할 수 있습니다. 후원·구독 알림과 플로팅 새 채팅은 기존 배치를 유지합니다.
- 채팅 정리 숨김 규칙이 후원/미션 팝업 내부 버튼과 상세 패널까지 숨기지 않도록 예외 처리합니다.
- `배지 모아 챗`이 같은 채팅 기능을 제어 중이면 충돌을 피하기 위해 해당 기능을 자동으로 양보합니다.
- 라이브를 보다가 다른 치지직 페이지로 이동해 영상이 미니플레이어로 바뀌면, 기본 꺼짐 옵션으로 미니플레이어 아래에 채팅을 함께 붙일 수 있습니다. 미니플레이어 자체를 드래그해 위치를 이동하고 우하단 손잡이로 영상 크기, 채팅 아래쪽 손잡이로 채팅 높이를 각각 조절할 수 있으며 마지막 크기와 위치를 저장합니다.
- 지원되는 Chromium 브라우저에서는 독립 채팅 팝업을 항상 위 Picture-in-Picture 창으로 열 수 있습니다. 실행 중에는 원본 팝업의 채팅을 가리고 가운데에 원본 채팅으로 돌아오는 버튼을 표시하며, 이 실험 옵션은 기본적으로 꺼져 있습니다.
- 항상 위 채팅은 별도 iframe으로 열리므로 다른 확장이 하위 프레임 주입을 지원하지 않으면 해당 확장의 UI가 Picture-in-Picture 창 안에 나타나지 않을 수 있습니다.

### 채팅 리캡

- `내 채팅 기록`을 켜면 라이브와 다시보기에서 본인이 보낸 일반 채팅·후원·구독 메시지만 브라우저에 저장합니다. 기본값은 꺼짐이며 보관 기간은 무제한, 1년, 90일 중에서 선택할 수 있습니다.
- 전용 리캡 페이지에서 전체·이번 달·최근 30일 요약, 첫 채팅과 올해 첫 채팅, 하루 최다 채팅, 연속 채팅, 채널별 채팅, 월별 추이, 요일·시간대 분포, 자주 쓴 말과 이모티콘을 확인할 수 있습니다.
- 채널별 목록·카드 보기와 상위 채널 포디움, 히트맵, 단어 상세 추이, 채팅 후원·구독 내역을 제공합니다. 채널별 목록은 여러 채널을 함께 펼칠 수 있고 모든 기록 채널을 표시하며, 카드와 목록의 현재 상태를 포함한 여러 형태를 이미지로 저장할 수 있습니다.
- 라이브의 `내 채팅 기록`에서 기간·키워드·스트리머로 기록을 검색하고, 다시보기와 후원·구독 기록을 선택해 가져올 수 있습니다. 이미 수집한 영상은 메시지 식별자와 재생 시각을 함께 비교해 중복을 줄이며, 수집한 채널에 새 다시보기가 생기면 배지로 알리고 해당 채널을 미리 선택합니다.
- 요약·채널·활동 시간대·월별 추이·자주 쓴 표현과 상세 분석을 이미지로 저장할 수 있습니다. 저장 전 외부 이미지를 안전하게 포함하고 글꼴과 프로필 로딩을 기다리며, 상세 이미지에는 분석 항목 이름을 함께 표시합니다.
- 원하는 통계 항목을 골라 AI 분석용 프롬프트를 만들고 미리 본 뒤 복사할 수 있습니다. 프롬프트는 관찰과 해석을 구분하고 데이터 범위·수집 누락·불확실성을 밝히도록 구성하며, 확장이 분석 데이터를 자동으로 외부에 전송하지는 않습니다.
- 미구독 채널의 기간제 이모티콘은 저장된 이미지 대신 이름으로 표시합니다.
- 채팅 기록은 계정·채널·월 단위로 나누고, 한 달에 5,000건을 넘는 기록은 추가 청크에 계속 보관합니다. 기존 단일 청크 기록도 별도 변환 없이 읽으며 사용자 데이터 포함 백업에는 추가 청크까지 포함합니다.
- 큰 기록은 단계적으로 렌더하고 날짜·월·요일·시간대 집계를 한 번만 만들어 여러 차트에서 재사용합니다. 단어 상세 통계도 선택할 때 계산해 리캡 진입과 스크롤 부담을 줄입니다.
- 리캡 페이지는 현재 로그인한 치지직 계정의 기록만 표시합니다. 로그아웃 상태나 로그인 확인 실패는 저장된 기록이 없는 상태와 구분해 안내하며, 기록 자체는 삭제하지 않습니다.
- 리캡을 열어 둔 동안 다른 탭에서 채팅이 추가되면 즉시 전체 재집계하지 않고 `새 기록 있음`으로 알립니다. 저장소를 읽지 못한 경우에는 기록 없음과 구분해 표시하고 기록 인덱스를 다시 만들 수 있습니다.
- 사용자 데이터 포함 백업에는 채팅 리캡 기록·수집 이력·표시 설정이 포함됩니다. 기록과 분석 결과는 외부로 전송하지 않습니다.

### 사용자 차단

- 다시보기·커뮤니티·클립 댓글과 라이브·다시보기 채팅에서 사용자를 치즈 플래터 차단 목록에 등록해 해당 사용자의 댓글과 채팅을 숨길 수 있습니다.
- 댓글과 채팅 프로필의 차단 버튼에서 선택적인 차단 사유를 기록하고, 필요하면 치지직 자체 사용자 차단도 함께 적용할 수 있습니다. 채팅 프로필 팝오버의 `치즈 플래터 차단·해제` 버튼은 설정에서 별도로 표시할 수 있으며 기본값은 꺼짐입니다. 버튼을 숨겨도 기존 차단 목록과 댓글·채팅 숨김은 유지됩니다.
- 기능 설정의 `사용자 차단 관리` 탭에서 UID를 직접 입력해 사용자를 로컬 또는 치지직에 차단할 수 있습니다.
- 닉네임·차단 사유·UID·이전 닉네임 검색, 닉네임 변경 이력 확인, 개별·선택·전체 해제를 지원합니다.
- 차단 목록은 닉네임, 차단 사유, 차단 일시, 치지직 차단 여부와 이전 닉네임 이력을 포함해 JSON 또는 CSV 파일로 내보낼 수 있습니다.
- 치지직 자체 차단이 함께 적용된 사용자는 로컬 목록만 해제하거나 치지직 차단까지 함께 해제할 수 있습니다.
- 치지직이 표시하는 `내가 차단한 이용자의 댓글입니다.` 안내 줄을 별도 옵션으로 숨길 수 있습니다.
- 차단 목록이 많아져도 설정 화면이 무거워지지 않도록 가상 스크롤, 검색 입력 지연 처리, 닉네임 조회 동시 요청 제한을 적용합니다.
- 차단 목록을 길게 스크롤하면 나타나는 위쪽 화살표 버튼으로 목록 최상단에 바로 돌아갈 수 있습니다.

### 통나무파워

- 라이브 채팅 입력창 부근에 현재 채널의 보유 통나무파워를 표시할 수 있습니다.
- 통나무파워 배지에 마우스를 올리면 정확한 보유량을 함께 표시하고, 클릭 시 상위 보유 채널 팝업을 열거나 통나무파워 페이지로 이동하거나 동작하지 않도록 설정할 수 있습니다.
- 상위 보유 채널 팝업은 전체 합계, TOP N 합계, 채널별 보유량과 새로고침을 제공하며, 표시 개수는 설정에서 `5~99`개로 조절할 수 있습니다.

- 사이드바와 헤더의 팔로잉 라이브 채널에 마우스를 올리면 라이브 영상 미리보기 패널을 표시하고, 패널 크기 조절과 고정 표시를 지원합니다.
- 팔로잉 라이브 미리보기는 설정한 자동 종료 시간이 지나면 닫히며, 같은 채널에 계속 호버 중일 때 즉시 다시 열리지 않도록 처리합니다. 사이드바 스크롤 중에는 미리보기 열림을 잠시 미뤄 불필요한 팝업을 줄입니다.
- 팔로잉 라이브 미리보기는 음소거 고정, 음소거 해제 시 볼륨, 휠 음량 조절 활성 지연, 라이브 최신 지점 재생, 썸네일만 보기, 제목 전체 표시, 헤더 폰트 크기 조절(75~175%)을 지원합니다. 미리보기 컨트롤에서 직접 바꾼 음소거와 볼륨은 현재 미리보기 동안 존중합니다.
- 미리보기 헤더를 영상 위 또는 아래에 배치하고, 제목을 한 줄 전체에 표시한 뒤 프로필·채널명·경과 시간·카테고리를 아래 행에 배치하는 라이브 카드식 레이아웃을 선택할 수 있습니다. 카드식 레이아웃의 시청자 수 배지는 네 모서리 중 원하는 위치에 놓을 수 있습니다.
- 미리보기 헤더와 카드식 시청자 수 배지를 완전히 숨겨 영상만 표시할 수 있습니다. 이 모드에서는 사이드바 미리보기를 채널 툴팁 아래의 사이드바 바깥쪽 경계에 맞추고, 헤더 미리보기는 툴팁 오른쪽에 배치합니다. 공간이 부족하면 각각 반대 방향으로 전환하며, 헤더를 이용한 미리보기 이동과 고정은 사용하지 않습니다.
- 미리보기 제목·채널명·카테고리·경과 시간의 색상을 라이트·다크 모드별로 지정할 수 있으며, 카테고리 테두리와 배경은 선택한 색상에서 함께 계산합니다.
- 팔로잉 라이브 미리보기 헤더의 제목, 프로필 사진, 채널명, 카테고리, 시청자 수, 경과 시간을 항목별로 숨길 수 있습니다.
- 팔로잉 라이브 미리보기 영상 로딩이 실패하면 패널을 닫지 않고 썸네일로 대체 표시합니다.
- 치지직 팔로잉 탭에서 `팔로잉 정리` 버튼을 열어 최근 방송일 기준으로 채널을 확인하고, 개별/선택/필터 전체 언팔로우를 실행할 수 있습니다. 정리 목록의 프로필 이미지나 채널명을 클릭하면 해당 채널을 새 탭으로 열 수 있습니다.
- 채널 홈 탭 영역에 현재 채널의 라이브 페이지로 이동하는 바로가기 버튼을 표시할 수 있고, 라이브/오프라인 상태에 따라 버튼 스타일을 구분합니다.
- 라이브 카드에도 팔로잉 미리보기와 같은 별도 미리보기 패널을 사용할 수 있습니다.
- 라이브 탐색 카드 미리보기 위에서 우클릭으로 음소거를 토글하고, 마우스 휠로 미리보기 음량을 조절할 수 있습니다. 처음 음소거를 해제할 때 적용할 기본 음량은 `1~100%` 범위로 설정할 수 있습니다.
- 라이브 탐색 카드 미리보기의 표시 위치를 자동, 왼쪽 우선, 오른쪽 우선으로 선택할 수 있으며, 화면 경계에서는 반대편이나 더 넓은 쪽으로 자동 배치합니다.
- 팔로잉/채널 항목에 마우스를 올리면 최근 방송일, 팔로우 시작일, 첫 방송일, 총 방송 시간을 별도 툴팁으로 확인할 수 있습니다. 채널 페이지에서 줄여 표시된 팔로워 수에 마우스를 올리면 정확한 수를 확인하도록 설정할 수도 있습니다.
- 채널 다시보기 목록 카드의 날짜 텍스트에 마우스를 올리면 정확한 등록일과 방송 시작 시각을 툴팁으로 확인할 수 있습니다. 해당 영상을 시청하며 다시보기 채팅 기준값을 확보한 경우 `채팅 기준`, 그렇지 않으면 `추정`으로 구분하며, 제목·채널명·카테고리·태그에는 날짜 툴팁을 표시하지 않습니다.
- 채널·팔로잉·검색·라이브 카드·댓글·커뮤니티·헤더와 사이드바의 프로필 모서리 적용을 켜고 끄거나 `0~50%` 범위로 조절할 수 있습니다.
- 채팅 메시지와 구독·후원 메시지의 프로필 버튼 및 배지 이미지는 채널 프로필 모서리 적용 대상에서 제외합니다.
- 방송 중 프로필의 그라디언트 테두리 각도와 시작색·끝색·투명도를 사용자 지정하고, 프로필 모서리가 함께 반영되는 미리보기에서 결과를 확인할 수 있습니다.
- 일부 다시보기에 자동 생성되는 AI 챕터 제목과 재생바의 챕터 강조를 설정에서 숨길 수 있습니다.
- 다시보기의 `영상 더보기` 영역을 영상 아래로 옮기거나 숨길 수 있으며, 숨길 때 자동 재생 스위치가 켜져 있으면 먼저 끕니다.
- `영상 더보기`를 숨기지 않아도 다시보기의 `자동 재생 사용 설정`을 자동으로 끄도록 설정할 수 있습니다.
- 채팅창이 없는 다시보기에서 `영상 더보기` 배치/숨김을 적용할 때 영상 영역 오른쪽에 빈 공간이 남지 않도록 플레이어 폭을 보정합니다.

- 확장 아이콘을 누르면 좌측 카테고리 탭(`전체`, `플레이어`, `오디오 믹서`, `비디오 필터`, `다시보기`, `검색`, `라이브 탐색`, `헤더`, `사이드바`, `전용 팔로잉 목록`, `미리보기`, `팝업 플레이어`, `채널·프로필`, `팔로잉·구독`, `채팅`, `통나무파워`, `클립·카페`, `사용자 차단 관리`)으로 구분된 기능 설정 팝업을 열 수 있습니다.

- 다시보기 페이지에서 플레이어를 클릭하지 않고 좌우 방향키로 `5초`씩 이동하는 전역 방향키 옵션을 켜고 끌 수 있습니다.
- 동영상·클립 검색 결과가 있는 상태에서 다른 탭이나 창에 갔다가 돌아오면 검색을 자동으로 초기화하도록 설정할 수 있습니다.
- 실시간 따라잡기 민감도와 시작·목표 지연, 배속·즉시 이동 방식, 따라잡기 배속, 자동 재발동 쿨다운을 설정할 수 있습니다.
- `라이브 탐색` 탭에서 제외 필터 버튼 표시 여부와 제외 태그·카테고리 목록을 관리할 수 있습니다.

- 라이브·카테고리·동영상 탐색에서 `차단한 유저` 카드 자리표시를 완전히 숨길 수 있습니다.
- 네이버 카페 게시글의 치지직 클립 링크를 글 안에서 바로 재생하는 기능을 켜고 끌 수 있습니다.
- 라이트 모드와 다크 모드를 지원하며, 우측 패널만 스크롤되고 팝업을 열 때마다 `전체` 탭에서 시작합니다.

- 재생 영역에서는 좌우 방향키를 `1~5초`, `Shift + 방향키`를 `0.1~0.9초` 간격으로 설정해 이동할 수 있고, 원본 시커와 구간 엣지의 마우스 조작을 유지합니다.

### 네이버 카페

- 네이버 카페 게시글의 치지직 클립 링크와 OG 링크를 감지해 게시글 안에 치지직 임베드 플레이어를 삽입합니다.
- 단독 텍스트 링크는 카페 OG 링크 카드 형태로 보정하고, 중복된 텍스트 링크는 정리합니다.
- 치지직 클립 메타데이터를 가져와 스트리머 이름, 클립 제목, 썸네일 비율을 반영합니다.
- 세로형 클립은 썸네일 비율에 맞춰 세로 플레이어 레이아웃으로 표시합니다.
- 카페 클립 자동재생을 켜면 화면에 가장 잘 보이는 클립 하나를 자동재생하고, 화면에서 벗어나면 재생을 멈추며 장시간 벗어난 클립은 iframe을 제거해 미디어 자원을 해제합니다. 플레이어 준비가 늦으면 제한 시간 동안 재시도하고, 소리 있는 자동재생이 브라우저 정책에 막히면 음소거 재생으로 전환합니다. 음소거 유지 옵션을 해제한 경우 플레이어를 한 번 조작한 뒤 소리를 활성화합니다.
- 카페 글쓰기·수정 화면과 해당 에디터 iframe에서는 작성 중인 본문을 건드리지 않도록 클립 링크 변환을 실행하지 않습니다.
- 같은 카페 클립 인라인 재생 기능을 가진 기존 확장이 감지되면 중복 렌더링을 피하기 위해 자동으로 양보합니다.
- 기능 설정의 `클립·카페` 탭에서 `카페 클립 인라인 재생`을 끄면 새로고침 후 카페 페이지에서는 동작하지 않습니다.

### 클립 보관함

- 치지직에 로그인한 상태에서 클립 탐색 카드와 재생 화면의 클립을 즐겨찾기하고, 기능을 켠 뒤 좋아요한 클립을 브라우저에 기록해 모아 볼 수 있습니다. 로그아웃 상태에서는 보관함을 표시하지 않으며, 여러 치지직 계정을 사용하면 즐겨찾기와 기록된 좋아요를 계정별로 나누어 보관합니다.
- 클립 탐색 페이지의 전체 폭 보관함 보기에서 `즐겨찾기`와 `기록된 좋아요`를 전환하고 제목·채널 검색과 최근 저장순·오래된 저장순·인기순·좋아요순·제목순·채널명순 정렬을 사용할 수 있습니다.
- 보관함을 열거나 즐겨찾기·기록된 좋아요 탭을 전환하면 저장된 재생수와 좋아요 수를 먼저 표시하면서 현재 첫 화면의 값을 즉시 다시 조회해 보관함 저장값에도 반영합니다. 이후 더보기 항목은 `30분` 캐시를 사용하며, 한 번 연 보관함에서는 최대 `120개`까지만 갱신해 대량 보관 시 API 요청과 CPU 부하가 급증하지 않도록 제한합니다.
- 보관함 카드에는 재생수와 좋아요 수를 각각 아이콘과 함께 표시하며, 클립 재생 화면에서 저장된 제목 앞에 채널명이 중복된 경우 이를 제거해 원래 클립 제목으로 정리합니다.
- `날짜별 모아보기`를 켜면 정렬 방식과 별개로 `오늘`, `어제`, `26년 8월 12일`과 같이 저장 날짜별로 나누어 표시합니다. `스트리머별 모아보기`를 켜면 채널별 폴더로 묶어 각각 접고 펼칠 수 있으며, 두 옵션을 함께 켜면 스트리머 폴더 안을 다시 날짜별로 나눕니다. 선택한 보기와 정렬 기준은 다음 방문에도 유지됩니다.
- 스트리머 폴더는 채널 ID가 없는 이전 보관 항목도 같은 닉네임에서 하나의 채널 ID만 확인되면 해당 채널 폴더에 함께 표시합니다.
- 원본 클립 목록과 필터 상태는 보관함을 닫을 때 그대로 복원하며, 보관량이 많아도 한 번에 `60개`씩 표시해 화면 렌더링 부담을 제한합니다.
- 치지직은 좋아요한 클립 전체 목록을 제공하지 않으므로 `기록된 좋아요`에는 보관함 기능을 켠 뒤 감지한 클립을 우선 표시합니다. `팔로잉 좋아요 가져오기`를 누르면 팔로잉 채널을 `5개` 단위로 자동 순회하고 채널별 전체 클립을 커서 끝까지 확인해, 과거에 좋아요한 팔로잉 채널의 클립도 보관함에 추가할 수 있습니다. 한 작업에서는 클립 목록 최대 `4페이지`와 좋아요 후보 약 `100개`씩만 처리한 뒤 다음 작업으로 자동 연결해 순간 요청량과 메모리 사용을 제한합니다. 실행 중에는 `일시정지` 후 저장된 위치부터 이어가거나 `중지`할 수 있으며, 이미 추가된 클립은 유지됩니다. 좋아요 확인 실패 항목은 현재 커서를 넘기기 전에 재시도하고, 끝내 확인하지 못하면 해당 위치를 유지한 채 중단합니다. 진행 중에는 완료 채널의 평균 클립 수와 실제 처리 속도를 바탕으로 예상 남은 시간을 표시합니다.

### 팝업 검색

- 채널 페이지의 `팝업` 버튼으로 넓은 별도 창에서 검색할 수 있습니다.
- 스트리머 닉네임으로 다른 채널의 다시보기와 클립을 검색할 수 있습니다.
- 검색 후보가 여러 명이면 사용자가 직접 채널을 선택할 수 있습니다.
- 후보 목록에는 채널 이미지, 채널명, 공식 인증 마크가 표시되며, 채널 ID는 필요할 때만 보거나 복사할 수 있습니다.
- 공식 인증 마크 이미지를 불러오지 못하면 텍스트 배지로 대체합니다.
- 클립 팝업의 초기 준비 상태와 검색 중 상태에는 스켈레톤 UI와 animated SVG를 표시합니다.
- 채널명이 전달되지 않은 팝업도 채널 정보를 다시 확인해 검색 대상에 UID 대신 채널명을 표시합니다.
- 라이트 모드와 다크 모드를 지원합니다.

### 안정성과 캐시

- API 요청과 전체 수집은 background service worker에서 처리합니다.
- 다시보기와 클립은 페이지당 최대 `50개`씩 요청합니다.
- 댓글 타임스탬프는 치지직 댓글 API에서 최대 `5페이지`까지 확인하고, 결과를 `30분` 동안 메모리에 캐시합니다.
- 다시보기는 나머지 페이지를 최대 `3개`까지 병렬 요청합니다.
- 클립은 커서 기반 페이지네이션이므로 순차적으로 수집합니다.
- 클립 좋아요순 정렬에 필요한 좋아요 수는 별도 반응 API로 조회하며, 지연이나 실패가 반복되면 검색 완료를 우선합니다.
- 서로 다른 전체 수집 작업은 최대 `2개`까지만 동시에 실행하고 나머지는 대기합니다.
- 동일한 목록을 여러 화면에서 동시에 요청하면 진행 중인 수집 작업을 공유합니다.
- 검색 중에는 content의 `검색` 버튼과 팝업 새로고침 버튼이 `검색 중지` 동작으로 바뀝니다.
- 수집 결과는 메모리와 `chrome.storage.local`에 캐시하며, 기본 TTL은 `1시간`입니다.
- 큰 클립 목록은 chunk 단위로 저장하고, content와 팝업 모두 chunk 캐시를 복원할 수 있습니다.
- 클립이 중간에 삭제될 수 있으므로 누락 항목은 한 번 더 확인한 뒤 삭제된 항목으로 처리합니다.
- 치지직 스튜디오의 `내가 만든 클립` 삭제 XHR을 감지해 원본 페이지와 검색 캐시를 함께 갱신합니다.
- 팔로잉/라이브 카드 미리보기에서 HLS 재생이 필요할 때만 `hls.js`를 지연 주입해 초기 페이지 로딩 부담을 줄입니다.
- 치지직 iframe 안에서도 검색/플레이어 보조 기능이 필요한 경우 동작하도록 주요 content script를 모든 프레임에 주입합니다.
- 클립 만들기 에디터에서는 오디오 믹서·비디오 필터·content 초기화 로직이 개입하지 않도록 해 구간 조절 슬라이더 조작 부담을 줄입니다.
- 탭 복귀 시 검색 자동 초기화 옵션이 켜져 있으면 이전 검색 결과의 세션 복원을 건너뛰어 복귀 후 원본 목록을 우선 표시합니다.
- 치지직 페이지의 CSS 모듈 클래스명이 변경되어도 동영상/클립 링크와 현재 DOM 구조를 함께 확인해 검색 도구와 결과 목록을 복구합니다.
- 치지직의 새 시맨틱 색상 변수와 라이트·다크 테마용 자체 fallback 색상을 함께 사용해 원본 테마 변수 변경에도 검색·팝업 UI 색상을 유지합니다.
- 통합검색 동영상 재정렬은 원본 React 리스트를 직접 재배열하지 않고 숨긴 뒤 클론 리스트를 렌더해 치지직 재렌더와 충돌하지 않도록 처리합니다.
- 통합검색 클립 후보는 검색어·날짜 범위별로 `10분` 동안 메모리에 캐시해 재검색 시 저장 결과를 먼저 표시하고, 추가 수집 중에는 기존 결과나 스켈레톤 UI를 유지합니다. 원본 검색 결과가 없어도 클립 수집을 끝까지 확인한 뒤 최종 빈 결과를 표시합니다.
- 채팅 리캡은 계정·채널·월 단위 저장소와 경량 카탈로그를 사용해 필요한 기록만 읽습니다. 오래된 단일 저장 형식은 최초 한 번 분할하고, 다시보기 수집과 대량 집계 중에는 주기적으로 메인 스레드에 실행권을 돌려줍니다.
- 클립 페이지 오디오 믹서는 상위 페이지가 지정한 실제 표시 iframe 하나에만 연결하고, 화면 밖에 미리 로드된 클립에서는 오디오 그래프·노멀라이저·타이머·옵저버를 중단합니다.
- 클립 페이지 비디오 필터도 실제 표시 iframe 하나에만 적용합니다. 스크롤 전환 중에는 GPU 필터와 프레임 측정을 잠시 해제하고, 숨김 탭에서는 측정을 멈추며 드롭이 이어지면 선명도를 단계적으로 낮춥니다.
- 치지직 탭 초기화 시 여러 설정값을 한 번에 미리 읽어 콘텐츠 스크립트의 저장소 IPC 호출을 줄입니다.
- 사이드바 재렌더 감지는 짧게 디바운스해 팔로잉/헤더 UI 재적용이 과도하게 반복되지 않도록 처리합니다.
- 팔로잉 자동 펼침은 네트워크나 React 렌더가 느릴 때도 바로 중단하지 않고 몇 차례 더 기다려 조기 중단을 줄입니다.
- 플레이어와 채팅의 DOM 감시는 변경을 묶어 처리하고 숨겨진 탭에서는 UI 보정을 쉬어, 채팅이 빠른 방송이나 여러 방송 탭에서 발생하는 메인 스레드 부하를 줄입니다.
- 비디오 필터의 DOM 감시는 변이가 몰려도 최대 `250ms`마다 한 번 처리하고 숨겨진 탭에서는 옵저버와 프레임 측정을 중단했다가 복귀 시 상태를 한 번 보정합니다.
- 채팅 타임스탬프와 블라인드 복원은 이미 처리한 행을 다시 분석하지 않으며, React 재렌더로 시간 요소가 사라진 행과 준비가 늦은 행만 제한적으로 재처리합니다.
- 전용 팔로잉 목록은 최상위 프레임에서만 자동 갱신하고, 응답 내용이 실제로 달라졌을 때만 목록을 다시 렌더하거나 즐겨찾기 메타데이터를 저장합니다.
- 전용 팔로잉 목록 자체의 DOM 변경은 전역 사이드바 옵저버의 재초기화 대상에서 제외하고, 미리보기 요청·타이머·오래된 캐시를 닫기와 전환 시 정리합니다.
- 채널 라이브 상태, 팔로잉 최근 방송, 다시보기 채널 매핑처럼 오래 켜둔 탭에서 누적될 수 있는 캐시는 최대 크기를 제한합니다.
- 수신함 커뮤니티 소식은 알림을 켠 팔로잉 채널만 최대 `4개`씩 확인하고 최근 `30일`, 최대 `300개` 글의 본문과 첨부 메타데이터를 로컬에 보관합니다. 첨부 이미지는 글을 펼칠 때만 불러오며, 라운지 소식과 확인 주기를 공유하고 두 기능을 모두 숨기거나 브라우저 탭이 보이지 않으면 수집을 중단합니다.
- 기능 설정의 표시/숨김 상태와 실시간 따라잡기 민감도는 `chrome.storage.local`에 저장하고 열린 치지직 탭에 즉시 반영합니다.
- 사용자 차단 목록의 `userIdHash`, 닉네임과 변경 이력, 선택적 차단 사유, 차단 시각과 치지직 차단 여부는 `chrome.storage.local`에만 저장하며 댓글·채팅 필터링과 차단 관리에 사용합니다.
- 스트림 정보는 치지직이 `UNK`처럼 불명확한 코덱 값을 주는 경우 오디오 프로파일과 오디오 전용 트랙 정보를 이용해 AAC 등으로 보정합니다.
- 오디오 믹서 설정은 현재 라이브/다시보기 기준으로 저장하고, 커스텀 프리셋은 전체 플레이어에서 공유합니다. 채널 이동 직후 저장 타이밍에도 커스텀 프리셋 목록이 빈 값으로 덮이지 않도록 보호하고, 초기 저장값 요청이 유실되면 제한된 횟수로 다시 요청합니다.
- 비디오 필터 설정은 현재 라이브/다시보기 기준으로 저장하고, 커스텀 프리셋은 전체 플레이어에서 공유합니다. 채널 저장값을 불러오기 전 자동 활성화·저장을 막고, 초기 요청이 유실되면 제한된 횟수로 다시 요청합니다.
- 통나무파워 시청 적립 상태는 `chrome.alarms`와 `chrome.storage.session`을 사용해 백그라운드에서 채널별로 추적합니다.
- 통나무파워 지우개는 `game.naver.com/profile` 페이지에서 동작하며, 숨김 목록은 `chrome.storage.local`에 저장해 상위 보유 팝업과 공유합니다.
- 확장 프로그램 설치 또는 업데이트 시 열려 있는 치지직과 치지직 스튜디오 탭에 새로고침 안내를 표시하며, 고정 배너·잠시 표시·토스트 중 방식을 고르거나 업데이트 안내를 끌 수 있습니다. 잠시 표시와 토스트는 `3·5·10·15초` 중 노출 시간을 선택할 수 있고, 토스트는 3×3 위치 선택기로 화면의 아홉 위치 중 하나를 지정할 수 있습니다. 전체 기능 스위치와 설정 불러오기 후 적용 안내는 이 설정과 관계없이 표시되며, 어느 경우에도 사용자가 버튼을 누르기 전에는 페이지를 새로고침하지 않습니다.

## 설치

### Chrome / Chromium

1. `chrome://extensions/`를 엽니다.
2. 우측 상단의 `개발자 모드`를 켭니다.
3. `압축해제된 확장 프로그램을 로드`를 누릅니다.
4. 이 프로젝트 폴더를 선택합니다.

## 사용 방법

### 채널 페이지에서 검색

1. `https://chzzk.naver.com/{channelId}/videos` 또는 `https://chzzk.naver.com/{channelId}/clips`로 이동합니다.
2. 페이지에 추가된 치즈 플래터 검색 도구에서 검색어와 필터를 설정합니다.
3. `검색` 버튼을 눌러 목록을 불러옵니다.
4. 목록을 가져온 뒤에는 검색어, 기간, 유형, 정렬 조건을 바꿔 즉시 다시 필터링할 수 있습니다.

### 다시보기 타임스탬프

1. 치지직 다시보기 재생 페이지(`/video/{videoNo}`)로 이동합니다.
2. 댓글에 포함된 `1:23`, `1:23:45`, `(1:23)` 같은 타임스탬프를 자동으로 수집합니다.
3. 수집된 타임스탬프는 플레이어 슬라이더에 마커로 표시되며, 마커를 클릭하면 해당 시점으로 이동합니다.
4. 마커에 마우스를 올리면 플레이어 미리보기 아래에 댓글 내용이 표시됩니다.
5. 재생바를 탐색하면 미리보기 시간 아래에 채팅 기준 또는 추정 방송 시각이 함께 표시됩니다.
6. 플레이어 하단의 댓글 타임스탬프 버튼을 누르면 전체 타임스탬프 목록을 팝업으로 확인할 수 있습니다.
7. 패널 상단 스위치로 재생바 마커 표시 여부를 켜고 끌 수 있습니다.
8. 댓글 타임스탬프 버튼을 우클릭하면 타임스탬프 기능 전체를 켜거나 끌 수 있습니다.

비슷한 타임스탬프는 `3초` 이내 기준으로 하나로 묶고, `bestComments`와 설명이 있는 댓글을 우선 표시합니다. 타임스탬프 목록은 현재 재생 구간을 강조하며, 타임스탬프가 없으면 버튼은 흐리게 표시되고 팝업이 열리지 않습니다.

### 오디오 믹서 사용

1. 치지직 라이브 또는 다시보기 재생 페이지로 이동합니다.
2. 플레이어 하단의 오디오 믹서 버튼을 눌러 패널을 엽니다.
3. 방송 유형에 맞는 프리셋을 선택하거나, 고급 슬라이더/전문가 모드에서 직접 값을 조정합니다.
4. 믹서가 켜진 상태에서는 플레이어 하단 믹서 버튼 옆 슬라이더로 마스터 게인을 빠르게 조정할 수 있습니다.
5. 프리셋을 수정한 설정은 `프리셋 추가`로 커스텀 프리셋에 저장할 수 있습니다.
6. 수정한 값은 `초기화` 버튼으로 수정 전 프리셋 값으로 되돌릴 수 있습니다.
7. 커스텀 탭의 `내보내기`/`불러오기`로 프리셋 JSON을 복사하거나 붙여넣을 수 있습니다.
8. 스트림 정보 버튼을 눌러 현재 재생 중인 영상/오디오 정보를 확인할 수 있습니다.
9. 라이브 지연이 큰 경우 `실시간 따라잡기` 버튼으로 재생 속도를 잠시 높여 지연을 줄일 수 있습니다.
10. `실시간 따라잡기` 버튼을 우클릭하면 자동 따라잡기를 켜거나 끌 수 있습니다.

### 비디오 필터 사용

1. 치지직 라이브 또는 다시보기 재생 페이지로 이동합니다.
2. 플레이어 하단의 비디오 필터 버튼을 눌러 패널을 엽니다.
3. 방송 유형에 맞는 화면 프리셋을 선택하거나, 슬라이더로 밝기와 색감을 직접 조정합니다.
4. 수정한 설정은 `프리셋 추가`로 커스텀 프리셋에 저장할 수 있습니다.
5. 선명도 값이 높아 영상이 버벅이면 `선명도 자동 조절`을 켜 프레임 드롭에 따라 선명도를 일시적으로 낮출 수 있습니다.
6. 커스텀 탭의 `내보내기`/`불러오기`로 비디오 필터 프리셋 JSON을 복사하거나 붙여넣을 수 있습니다.

### 기능 설정 사용

1. 브라우저 툴바에서 치즈 플래터 확장 아이콘을 누릅니다.
2. 넓은 화면이 필요하면 우측 상단의 새 탭 아이콘을 눌러 현재 카테고리를 새 탭으로 엽니다.
3. 좌측 카테고리 탭(`전체`, `플레이어`, `오디오 믹서`, `비디오 필터`, `다시보기`, `검색`, `라이브 탐색`, `헤더`, `사이드바`, `전용 팔로잉 목록`, `미리보기`, `팝업 플레이어`, `채널·프로필`, `팔로잉·구독`, `채팅`, `통나무파워`, `클립·카페`, `사용자 차단 관리`)에서 원하는 분류를 선택합니다.
4. 상단 검색창에 옵션 이름이나 설명 일부를 입력해 필요한 설정을 바로 찾을 수 있습니다.
5. 사용하지 않을 기능의 스위치를 켜면 해당 버튼이나 UI가 숨겨집니다.
6. 실시간 따라잡기 민감도에서 `낮음`, `보통`, `높음` 또는 `커스텀`을 선택합니다.
7. 사이드바를 숨겼다면 헤더 바로가기에 표시할 메뉴를 선택할 수 있습니다.
8. 클립 페이지의 `클릭하여 라이브 시청` 버튼은 기본적으로 숨겨지며, 필요하면 설정에서 다시 표시할 수 있습니다.

### 팝업에서 다른 채널 검색

1. 채널 페이지의 치즈 플래터 검색 도구에서 `팝업` 버튼을 누릅니다.
2. 팝업 상단의 스트리머 입력란에 닉네임을 입력합니다.
3. 검색 결과가 여러 명이면 후보 목록에서 원하는 채널을 선택합니다.
4. 해당 채널의 다시보기 또는 클립 목록을 검색합니다.

## 검색 문법

검색어는 일반 단어뿐 아니라 `OR`, `AND`, 제외 조건, 괄호를 조합할 수 있습니다.

| 기능              | 예시                                                          | 설명                                        |
| ----------------- | ------------------------------------------------------------- | ------------------------------------------- |
| 일반 검색         | `대회 결승`                                                   | 두 단어를 모두 포함한 결과를 찾습니다.      |
| OR 검색           | `대회 \| 결승`, `대회 OR 결승`                                | 하나 이상의 단어를 포함한 결과를 찾습니다.  |
| AND 검색          | `대회 AND 결승`                                               | 모든 단어를 포함한 결과를 찾습니다.         |
| 제외 검색         | `대회 -예선`                                                  | 특정 단어를 포함한 결과를 제외합니다.       |
| 괄호 조합         | `(대회 \| 이벤트) 결승`                                       | 여러 조건을 묶어서 검색합니다.              |
| 태그 검색         | `#게임`                                                       | 다시보기 태그에서 검색합니다.               |
| 카테고리 검색     | `@메이플`, `category:메이플`, `cat:메이플`, `카테고리:메이플` | 카테고리에서만 검색합니다.                  |
| 띄어쓰기 카테고리 | `category:"메이플스토리 월드"`, `@"메이플스토리 월드"`        | 빈칸이 포함된 카테고리를 정확히 검색합니다. |

다시보기는 제목, 태그, 카테고리를 대상으로 검색합니다. 클립은 제목과 카테고리를 대상으로 검색합니다.

통합검색 클립에서는 카테고리를 후보 범위로 지정할 수 있습니다. `@음악`은 음악 카테고리 클립을 우선 확인하고, `싱드컵 @음악`은 음악 카테고리 안에서 제목 또는 채널명에 `싱드컵`이 포함된 클립을 찾습니다. 공백이 있는 카테고리는 `@"종합 게임"` 또는 `category:"종합 게임"`처럼 따옴표로 묶어 입력합니다.

## 트러블슈팅

### 라이브 최초 진입 시 일부 채팅 시간이 보이지 않는 경우

- 원인: 초기 채팅 행에 시간이 먼저 삽입된 뒤 치지직의 후속 React 렌더가 확장 요소만 제거하면서 처리 완료 표시는 남을 수 있습니다.
- 처리: `1.27.0`부터 시간 요소가 사라진 행을 변이 시점에 다시 처리하고, React 데이터나 닉네임 준비가 늦은 행은 최대 4회만 짧게 재시도합니다.
- 확인: 확장을 다시 로드한 뒤 방송 페이지를 새로고침합니다. 다른 채팅 확장이 시간 표시를 담당 중이면 중복 방지를 위해 치즈 플래터가 자동으로 양보합니다.

### 다시보기 채팅을 탐색할 때 탭이 멈추는 경우

- 원인: 다시보기 채팅을 빠르게 탐색하면 치지직의 가상 목록이 많은 행을 연속 교체합니다. 이때 채팅 시간 표시와 원문 탐색을 매 변이마다 수행하면 메인 스레드 작업이 누적될 수 있습니다.
- 처리: 채팅 스크롤 중에는 행을 제한된 큐에만 모으고 입력이 잠시 멈춘 뒤 현재 DOM을 묶어서 처리합니다. 다시보기에서는 원문이 함께 제공되는 클린봇 메시지만 복원하고, 원문이 없는 블라인드 메시지는 한 번 확인한 뒤 재시도하지 않습니다. 탭을 숨기거나 기능을 끄면 대기 작업을 정리합니다.
- 확인: 확장을 업데이트한 뒤 열려 있던 다시보기 탭을 새로고침합니다. 계속 멈춘다면 `채팅 시간 표시`를 잠시 끄고, 문제가 발생한 다시보기 주소와 브라우저 종류를 함께 알려주세요.

### 팔로잉 목록 갱신 중 페이지가 무겁거나 미리보기가 늦게 닫히는 경우

- `1.27.0`부터 전용 팔로잉 자동 갱신은 최상위 프레임에서만 실행하고 데이터가 달라질 때만 DOM과 저장소를 갱신합니다.
- 미리보기에서 다른 채널로 이동하거나 페이지를 스크롤·전환하면 대기 중인 열기와 네트워크 요청을 취소하고, 오래된 재생 캐시를 정리합니다.
- 계속 부담이 크면 기능 설정에서 자동 갱신 주기를 늘리거나 끄고, 미리보기의 `썸네일만 보기`를 사용해 HLS 재생 부담을 줄일 수 있습니다.

### 비디오 필터 사용 중 영상이 버벅이는 경우

- `선명도 자동 조절`을 켜면 실제 영상의 드롭 프레임이 연속으로 높을 때 선명도를 단계적으로 낮추고, 안정 상태가 유지되면 천천히 복원합니다. 동작 중에는 필터 패널에 `성능 보호` 비율이 표시됩니다.
- 숨겨진 탭에서는 비디오 필터 DOM 감시와 프레임 측정을 중단합니다. 여러 방송 탭을 열었을 때도 보이지 않는 탭의 점검 부담을 줄입니다.
- 고선명도는 GPU 부담이 클 수 있으므로 하드웨어 가속을 켜거나 선명도 값을 낮추는 것이 좋습니다.

### 자동 실시간 따라잡기가 너무 자주 또는 느리게 동작하는 경우

- 기능 설정의 `플레이어` 탭에서 따라잡기 배속과 쿨다운을 조절합니다. 배속이 높을수록 지연은 빨리 줄지만 빠르게 재생되는 구간이 더 뚜렷하게 느껴질 수 있습니다.
- 쿨다운을 끄면 지연이 다시 커졌을 때 빠르게 재발동하지만, 배속 구간이 잦아질 수 있습니다. 기본·최대 간격을 늘리면 반복 발동을 줄일 수 있습니다.

## 패키징

Chrome용 `.zip`은 다음 명령으로 생성합니다.

```bash
./scripts/build-chrome-package.sh
```

Chrome 패키징 스크립트는 다음 작업을 수행합니다.

- Chrome용 `manifest.json`을 그대로 패키지에 포함합니다.
- `src`, `icons`, `popup.html`, `settings.html`, SVG 애셋, README를 임시 빌드 디렉터리에 복사합니다.
- `dist/chzzk-platter-chrome-v{version}.zip`을 생성합니다.

Firefox용 `.xpi`는 다음 명령으로 생성합니다.

```bash
./scripts/build-firefox-package.sh
```

Firefox 패키징 스크립트는 다음 작업을 수행합니다.

- Chrome용 `manifest.json`의 현재 버전을 기준으로 Firefox용 manifest를 생성합니다.
- Firefox용 manifest는 `background.scripts`와 `browser_specific_settings.gecko.id`(`@chzzk-platter.dev-lirpa`)를 사용합니다.
- `Chzzk-Platter-Firefox` 디렉터리를 생성해 Firefox용 빌드 파일을 갱신합니다.
- `Chzzk-Platter-Firefox` 디렉터리는 로컬 빌드 산출물이므로 Git 추적에서 제외합니다.
- `dist/chzzk-platter-firefox-v{version}.xpi`를 생성합니다.

## 배포 정책

- 실제 웹스토어에 배포한 버전만 `v{version}` 형식의 Git 태그를 생성합니다.
- `1.36.0`부터는 웹스토어 배포 시점에 GitHub Release도 함께 생성합니다.
- GitHub Release에는 README의 해당 버전 변경 내역과 Chrome ZIP, Firefox XPI를 첨부합니다.
- 배포하지 않고 다음 버전에 통합한 버전은 태그와 GitHub Release를 생성하지 않습니다.
- 아직 배포 전인 버전은 코드가 확정되고 웹스토어에 제출할 때까지 태그를 생성하지 않습니다.

## 참고 사항

- 치지직의 페이지 구조나 API가 변경되면 일부 기능이 동작하지 않을 수 있습니다.
- 전체 목록을 처음 불러오는 시간은 채널의 다시보기 또는 클립 개수와 네트워크 상태에 따라 달라집니다.
- 클립 목록은 커서 기반으로 수집하므로 다시보기보다 최초 로딩 시간이 길 수 있습니다.
- 댓글 타임스탬프 기능은 댓글 API 응답 구조와 플레이어 슬라이더 DOM 구조에 의존합니다.
- 오디오 믹서 기능은 브라우저 Web Audio API와 치지직 플레이어 DOM 구조에 의존합니다.
- 팔로잉 라이브 미리보기는 치지직 라이브 상세 API와 HLS 재생 환경에 의존하며, 브라우저나 네트워크 상태에 따라 로딩 시간이 달라질 수 있습니다.
- 비디오 필터 기능은 브라우저 CSS/SVG 필터와 치지직 플레이어 DOM 구조에 의존합니다.
- 선명도 필터는 브라우저와 기기 성능에 따라 부담이 클 수 있으며, 높은 선명도에서는 하드웨어 가속을 켜는 것이 좋습니다.
- 브라우저 정책상 같은 영상의 오디오는 하나의 `MediaElementSource`만 만들 수 있으므로, 다른 확장이 이미 오디오 그래프를 사용 중이면 오디오 믹서를 켤 수 없습니다.
- 실시간 따라잡기 기능은 치지직 라이브 플레이어의 레이턴시 정보와 브라우저 재생 속도 제어에 의존합니다.
- 클립 라이브 이동 버튼 숨김은 치지직 클립 페이지와 `m.naver.com/shorts` iframe DOM 구조에 의존합니다.
- 본 확장 프로그램은 치지직과 관련이 없으며, 네이버, 치지직, CHZZK은 NAVER의 등록상표입니다.
