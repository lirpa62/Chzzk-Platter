전체 기능

치즈 플래터 사용 전환은 페이지를 강제로 새로고침하지 않습니다. 열려 있는 관련 페이지에 안내가 나타나면 시청이나 작업을 마친 뒤 원하는 시점에 새로고침해 주세요. 새로고침 전까지는 기존 옵저버·타이머·주입 UI가 남거나 새 기능이 아직 시작되지 않을 수 있습니다.

업데이트 안내

  • └ 표시 방식 상단에 계속 표시하거나, 설정한 시간 동안만 상단 또는 선택한 위치의 토스트로 표시합니다
  • └ 표시 시간 잠시 표시와 토스트가 자동으로 닫힐 때까지의 시간을 선택합니다
  • └ 토스트 위치 토스트가 나타날 화면 위치를 선택합니다

안내를 끄거나 새로고침하지 않아도 현재 탭을 계속 사용할 수 있지만, 탭에 남아 있는 이전 버전의 스크립트·스타일 때문에 새 기능과 오류 수정이 적용되지 않거나 변경한 설정이 즉시 또는 일부만 반영될 수 있습니다. 업데이트 후 문제가 보이면 해당 탭을 새로고침해 주세요. 최초 설치 안내와 전체 기능 스위치·설정 불러오기 후 적용 안내는 이 설정과 관계없이 표시됩니다.

설정 이동

기능 설정, 커스텀 프리셋, 즐겨찾기와 그룹 구성을 JSON 파일로 내보내거나 다른 브라우저에서 불러옵니다. 캐시, 로그인 정보와 임시 시청 상태는 포함하지 않습니다.

불러오면 파일에 포함된 설정만 덮어쓰고 열린 관련 페이지에 새로고침 안내를 표시합니다. 페이지와 설정창을 강제로 다시 열지는 않으며, 설정창을 닫았다 다시 열면 불러온 값을 확인할 수 있습니다. 내보낸 파일에는 채널 ID, 즐겨찾기와 그룹처럼 직접 설정한 정보가 포함될 수 있으므로 공유할 때 내용을 확인해 주세요.

          실시간 따라잡기 민감도

          지연이 '시작' 값을 넘으면 자동으로 따라잡아 '목표' 값까지 줄입니다. 값이 작을수록 라이브에 바짝 붙지만 끊김이 잦을 수 있습니다. 커스텀은 시작 2~30초, 목표 1~10초(시작 > 목표).

          따라잡기 배속

          지연을 따라잡을 때의 재생 배속입니다. 높을수록 빨리 따라잡아 지연이 덜 밀리지만, 빨라지는 구간이 더 크게 느껴질 수 있습니다(지연 12초 이상은 배속 대신 즉시 라이브로 이동).

          자동 따라잡기 쿨다운

          따라잡기가 너무 자주 발동해 끊기지 않도록 재발동 사이에 두는 최소 간격입니다. 자주 발동하면 이 간격이 '기본'에서 '최대'까지 점점 늘어납니다. '끔'으로 하면 지연이 밀릴 때마다 거의 즉시 따라잡습니다 (대신 배속 구간이 잦아질 수 있음). 기본 5~120초, 최대 5~600초.
